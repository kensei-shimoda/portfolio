# Portfolio

個人ポートフォリオサイト。GitHub Pages でホスティング。

## デプロイ手順

1. このリポジトリを GitHub に push する
2. リポジトリの **Settings → Pages** を開く
3. Source を `Deploy from a branch` に設定
4. Branch を `main` / `(root)` に設定して Save
5. 数分後に `https://<username>.github.io/<repository>/` で公開される

## ファイル構成

```
portfolio/
├── index.html
├── style.css
└── README.md
```

## カスタマイズ

`index.html` 内の以下を自分の情報に書き換えてください：

- `Your Name` → 氏名
- `your@email.com` → メールアドレス
- `yourusername` → GitHub ユーザー名
- 経歴・スキル・プロジェクトの各セクション
